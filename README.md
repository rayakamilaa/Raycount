# 🌸 Rayc0unt - Calculator App

**Raycount** adalah aplikasi kalkulator multifungsi berbasis Android yang dirancang dengan antarmuka pengguna (*UI*) bernuansa *soft pastel pink*, bergaya minimalis, bersih, dan elegan. 

Aplikasi ini dikembangkan menggunakan **Kotlin** dan **XML Material Design Components** di Android Studio untuk memberikan pengalaman pengguna (*UX*) yang responsif dan nyaman di pandang.

---

## 📱 Fitur Utama Aplikasi

1. **Splash Screen Elegant**
   - Layar pembuka (*landing screen*) estetik dengan logo khas `Rayc[÷]unt` menggunakan simbol pembagian khusus.

2. **Main Calculator (Kalkulator Utama)**
   - Mendukung perhitungan aritmatika dasar (Penjumlahan, Pengurangan, Perkalian, Pembagian, Persen).
   - Tombol dengan palet warna pastel (Mint Green, Soft Pink, Purple, Magenta).
   - Tampilan angka presisi dengan *card display* efek bayangan lembut (3D soft elevation).

3. **Discount Calculator (Kalkulator Diskon)**
   - Menghitung potongan harga dan total pembayaran secara otomatis.
   - Dilengkapi *auto-formatting* pemisah ribuan otomatis untuk mata uang Rupiah (IDR).

4. **Currency / Kurs Converter (Konverter Mata Uang)**
   - Konversi nilai Rupiah (IDR) ke USD, SGD, dan KRW.
   - Pilihan menu dropdown (*Spinner*) khusus berlatar warna ungu soft (Lavender) dengan sudut rounded melengkung.

## 🛠️ Teknologi & Resource yang Digunakan

* **Language:** Kotlin
* **UI Layout:** XML (ConstraintLayout, Material CardView, MaterialButton)
* **Design Theme:** Custom Pastel Pink Palette (`#F8EBF0`, `#2D1F23`, `#E1BEE7`)
* **Fonts:** Serif Typeface
* **Target Device:** Android (Samsung Galaxy A10s Compatible)
